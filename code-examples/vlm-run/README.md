> Part of **[Free-LLM](https://free-llm.com)** — Open Directory of Free AI & LLM APIs

## About

An OpenAI-compatible gateway for vision, OCR and language models. Calls work anonymously (no Authorization header, or "Bearer vlmrun") within per-IP limits. A free account adds 100 credits (about $1) and higher rate limits. Every call is still priced per token or image, with a $0.001 minimum.

**Official Website:** [https://docs.vlm.run/gateway/rate-limits](https://docs.vlm.run/gateway/rate-limits)

**Full Details:** [https://free-llm.com/api/vlm-run](https://free-llm.com/api/vlm-run)
