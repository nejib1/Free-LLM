## About

Gonka Broker resells inference from the decentralized Gonka network through an OpenAI-compatible API (an Anthropic-format API is also documented). Accounts with a verified mobile number get a monthly grant of free tokens, usable with any model and renewed at the start of each calendar month (unused tokens expire). One free grant per phone number; VoIP and landline numbers are refused. No card required. Models: GLM-5.3 Flash, DeepSeek V4 Flash, MiniMax M2.7.
