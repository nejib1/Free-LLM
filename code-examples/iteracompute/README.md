## About

IteraCompute is an OpenAI-compatible inference API (tool calling, streaming) with a recurring free tier on its self-hosted Qwen3.8 27B: up to 30M tokens per month per account, 8,192 output tokens per request, 160K tokens per minute, no credit card (email or Google sign-in). The allowance resets on the 1st of each month (UTC) and returns HTTP 429 when used up; there is no automatic paid overage. Shared free capacity may queue and has no SLA. Young service (domain registered August 2026); the rest of its catalog, including resold closed models, is paid.
