## About

Token Harbor is a unified OpenAI- and Anthropic-compatible API gateway with one key, per-token pay-as-you-go pricing and optional Pass subscriptions. The $0 Free plan (no card) includes a free allowance that resets on a rolling 7-day period and a rotating lineup of free models (currently MiMo V2.6 Flash, DeepSeek V4.1 Flash and TH-Rudder). Free models must be enabled in the dashboard; while enabled, prompts and responses may be retained for diagnostics and model improvement.
