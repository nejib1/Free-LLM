## About

FreeInference is a free, OpenAI- and Anthropic-compatible LLM API run by the MadSys Lab at Harvard SEAS for open-source, research and education use. Sign-up is by email with no credit card, and free accounts can use GLM-5.3 Flash, DeepSeek V4 Flash, MiniMax M3 and Qwen3.6 35B (1M context on the larger models) plus bge-m3 embeddings. The quota is described as "generous" but not published, and requests may be logged for research (the lab has published anonymised agent traces). It has a native Anthropic endpoint, so it works with Claude Code without a proxy.

**Official Website:** [https://freeinference.org](https://freeinference.org)
