## About

A free, open-source, crowdsourced inference network where volunteers run the models. The oai.aihorde.net front puts an OpenAI-compatible chat completions API on top of the Horde's text workers. Requests without a key use the anonymous key 0000000000, at the lowest queue priority.

**Official Website:** [https://aihorde.net](https://aihorde.net)
