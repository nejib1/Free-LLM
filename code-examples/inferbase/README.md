## About

Inferbase is an OpenAI-compatible inference gateway with managed models and bring-your-own-key routing. The Free plan has no time limit and needs no card: 5,000 requests per month, including 100 managed requests and $0.50 of model usage per day on managed models priced up to $2 per million output tokens (for example GPT-OSS, Qwen3.6, Gemma 4, DeepSeek V4 Flash, Kimi K2.7 Code).
