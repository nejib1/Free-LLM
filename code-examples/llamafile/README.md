## About

Distribute and run LLMs as a single executable file. llamafile combines llama.cpp with Cosmopolitan Libc so the same file runs on Windows, macOS and Linux. The project moved to mozilla-ai/llamafile; version 0.10.6 (September 2026) tracks a recent llama.cpp with CUDA/HIP graphs and Vulkan support.

**Official Website:** [https://github.com/mozilla-ai/llamafile](https://github.com/mozilla-ai/llamafile)

**Full Details:** [https://free-llm.com/api/llamafile](https://free-llm.com/api/llamafile)
