## About

Vectoree is a backend for coding agents: models, auth, Postgres and storage behind one project key, with a CLI and an OpenAI-compatible gateway that works with Cursor, Claude Code and Codex. New accounts get a $5 welcome credit after CLI login (no card mentioned); after that you top up the organization wallet and pay per token at catalog prices. It is a trial credit, not a free tier.
