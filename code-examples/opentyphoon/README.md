## About

Typhoon is a family of Thai-English language models from SCB 10X. Its OpenAI-compatible API is a research showcase and free to use: Typhoon 2.5 30B A3B instruct at 5 requests/second and 200 requests/minute, plus Typhoon OCR and speech recognition. Usage data is collected to improve the models. Best for Thai-language apps.

**Official Website:** [https://opentyphoon.ai](https://opentyphoon.ai)
