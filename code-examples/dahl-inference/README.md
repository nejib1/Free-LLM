## About

Dahl Inference is an OpenAI-compatible API that resells capacity from the decentralized Gonka GPU network (operated by FROMZERO OÜ, Estonia, according to its terms). New accounts get their first 100 million tokens free. It is a one-time promotional grant with no monthly reset, and the terms let Dahl end free access at any time. Models include MiniMax M2.7, DeepSeek V4 Flash and GLM-5.3 Flash; read the current ids from GET /v1/models.
