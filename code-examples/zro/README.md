## About

Zro is a coding-focused inference service from MoonMath. The Free plan includes a daily allowance on GLM-5.3 Flash and DeepSeek V4.1 Flash that resets every day, through an OpenAI-compatible API with zero request retention and no training on requests. A CLI (`zro launch claude`) sets up Claude Code and other agents automatically. Paid plans start at $20/month or $5 usage packs.
