# رویداد | خبرخوان فارسی

خبرخوان مستقل و بدون وابستگی بیرونی در این مخزن. خبرها داخل مسیر `/news/<id>` باز می‌شوند؛ تیتر، چکیدهٔ RSS و پیوند گزارش اصلی را نشان می‌دهند. تصویر RSS در صورت وجود استفاده می‌شود؛ برای کارت‌های قابل‌مشاهدهٔ بی‌عکس و صفحهٔ داخلی، پیش‌نمایش محدود همان خبر برای خواندن Open Graph و چند پاراگراف انجام می‌شود، با فاصلهٔ درخواست و cache شش‌ساعته. متن کامل ذخیره یا بازنشر نمی‌شود. اگر ناشر تصویر واقعی ارائه نکند یا دسترسی ندهد، کاور گرافیکیِ دارای برچسب «عکس در RSS ناشر موجود نیست» نمایش داده می‌شود.

## اجرا

Python 3.10 یا جدیدتر لازم است. در پوشهٔ ریشهٔ مخزن:

```sh
NEWS_ADMIN_TOKEN='یک-کلید-تصادفی-بلند' python3 newsroom/server.py
```

خلاصه‌ساز محلی به `llama-cpp-python` و مدل Q4 حدود ۲۴۱ مگابایتی نیاز دارد. نصب runtime روی Python 3.14:

```sh
python3 -m pip install --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu llama-cpp-python==0.3.36
```

مدل با نام `gemma-3-270m-it-qat-Q4_0.gguf` در `~/.cache/roydad/models/` نگهداری می‌شود و وارد Git نمی‌شود.

سپس `http://127.0.0.1:8765` را باز کنید. پنل مدیریت در `/admin` است. برای دسترسی از شبکه، `NEWS_HOST=0.0.0.0` را تنظیم کنید و سرویس را پشت HTTPS و شبکهٔ مورداعتماد قرار دهید؛ کلید مدیریت را در مرورگر عمومی یا HTTP ساده استفاده نکنید. `NEWS_PORT` و `NEWS_DB_PATH` قابل تنظیم‌اند.

کلید مدیر از `NEWS_ADMIN_TOKEN` خوانده می‌شود؛ اگر env تنظیم نشده باشد، فایل محلی `newsroom/.admin-key` استفاده می‌شود. فایل کلید در Git نادیده گرفته شده است. برای چرخاندن کلید، فایل را عوض یا env را تنظیم و سرور را restart کنید.

## اتصال رسانه‌ها

۳۵ رسانهٔ داده‌شده در فهرست اولیه فقط با دامنه و نام ثبت شده‌اند و همگی غیرفعال‌اند. در پنل، «کشف و آزمایش فید» فقط `<link rel="alternate">` رسمی RSS/Atom را که خود صفحهٔ رسانه اعلام کرده بررسی می‌کند. مسیرهای RSS حدس زده نمی‌شوند. بعد از پاسخ XML معتبر، مدیر می‌تواند فید را فعال کند، فاصلهٔ دریافت را (حداقل ۵ دقیقه) و حالت انتشار هر منبع را تعیین کند. صف‌بندی سبک زمان‌بندی‌شده در همین فرایند سرور انجام می‌شود.

فهرست عمومی هر بار از دیتابیس تازه می‌شود، صفحه‌بندی ۲۰تایی دارد و در مرورگر هر ۶۰ ثانیه refresh می‌شود؛ دریافت از رسانه‌ها طبق فاصلهٔ تنظیم‌شدهٔ هر منبع (پیش‌فرض ۵ دقیقه، فناوری ۱۰ دقیقه) انجام می‌شود. صفحهٔ `/special` خبرهای منتخب مدیر را نشان می‌دهد و تا پیش از نخستین انتخاب، تازه‌ترین خبرها را با برچسب fallback نمایش می‌دهد.

بازنشر خودکار خبر به‌طور پیش‌فرض خاموش است: حالت پیش‌فرض «بازبینی مدیر» است. خلاصهٔ هوشمند به‌طور پیش‌فرض با مدل متن‌باز محلی Gemma 3 270M Q4 (`241,410,624` bytes) اجرا می‌شود؛ فایل مدل در `~/.cache/roydad/models/` قرار می‌گیرد و به مخزن اضافه نمی‌شود. با کلیک کاربر، فقط یک گزیدهٔ محدود از صفحهٔ اصلی خبر به مدل محلی داده می‌شود؛ متن از دستگاه خارج نمی‌شود، پاسخ cache و نرخ درخواست محدود می‌شود. برای تغییر مسیر مدل می‌توان `NEWS_AI_MODEL_PATH` را تنظیم کرد؛ اتصال OpenAI-compatible همچنان به‌عنوان fallback اختیاری از `NEWS_AI_BASE_URL`, `NEWS_AI_MODEL` و `NEWS_AI_API_KEY` پشتیبانی می‌کند. دسته‌بندی فعلی مبتنی بر واژه‌نامهٔ ساده است، نه مدل هوش مصنوعی. تشخیص خبر مشابه بر اساس شباهت دقیق تیتر نرمال‌شده است و رویداد چندمنبعی یا تناقض‌سنجی ایجاد نمی‌کند.

اعضا از `/members` حساب می‌سازند و درخواست دستیار می‌فرستند. مدیر از `/admin` درخواست را تأیید یا رد می‌کند؛ تأیید، نقش دستیار را روی حساب کاربر فعال می‌کند. دستیار فقط خبرهای اختصاصی خودش را از `/staff` می‌تواند ایجاد، ویرایش یا حذف کند؛ مدیر به همهٔ خبرها دسترسی دارد. رمزها salted PBKDF2 هستند و session token فقط به شکل hash ذخیره می‌شود.

برای اجرای تست‌های آفلاین:

```sh
python3 -m unittest discover -s newsroom -v
```

## محدودیت‌های نسخهٔ فعلی

- کشف فید خودکار است؛ API رسمی یا دسترسی جایگزین بررسی/پیاده‌سازی نشده است.
- فیدهایی که HTML صفحهٔ اصلی اعلام نکند، یا دسترسی‌شان محدود باشد، فعال نمی‌شوند؛ محدودیت دسترسی دور زده نمی‌شود. فیدهای خطادار غیرفعال و URL آن‌ها پاک می‌شود، اما نام رسانه برای گزارش وضعیت می‌ماند.
- AI به‌صورت پیش‌فرض محلی است؛ endpoint ابری فقط fallback اختیاری است.
- عکس‌های رسانه فقط از RSS یا Open Graph صفحهٔ همان خبر و دامنه/CDN تأییدشده می‌آیند؛ برای منبعی که تصویر ارائه نکند، عکس واقعی قابل‌ساختن یا حدس‌زدن نیست.
- در حال حاضر کاربران، احراز هویت چندمدیره، آمار بازدید، نمودارها، اعلان، تاریخچهٔ نسخه، API عمومی اختصاصی و جست‌وجوی انگلیسی وجود ندارد.
- برای مقیاس بالا، صف و زمان‌بند جداگانه، پایگاه دادهٔ سروری و احراز هویت استاندارد لازم است؛ SQLite و زمان‌بند داخلی برای نمونهٔ تک‌سرور هستند.

## ایمنی دریافت

دریافت فقط از HTTPS و همان دامنه یا زیردامنهٔ منبع پذیرفته‌شده انجام می‌شود؛ مقصدهای غیرعمومی، تغییر مسیر به دامنهٔ دیگر و پاسخ بیش از ۲ مگابایت رد می‌شوند. کلید مدیریت باید با `NEWS_ADMIN_TOKEN` تنظیم شود؛ بدون آن همهٔ عملیات مدیریتی قفل است.
