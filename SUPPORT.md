# Getting help

Pick the channel that matches what you need. It gets you an answer faster.

| I want to… | Go to |
|:---|:---|
| Ask how to use a provider, a free model or the router | [Discussions → Q&A](https://github.com/nejib1/Free-LLM/discussions) |
| Report a bug in **Free-LLM Router** | [Router bug report](https://github.com/nejib1/Free-LLM/issues/new?template=router-bug.yml) |
| Suggest a router feature | [Router feature request](https://github.com/nejib1/Free-LLM/issues/new?template=router-feature.yml) |
| Say a limit, model or price is wrong | [Correct provider data](https://github.com/nejib1/Free-LLM/issues/new?template=correct-data.yml), or the **Report an issue** button on the provider's page at [free-llm.com](https://free-llm.com) |
| Suggest a provider that is missing | [free-llm.com/submit](https://free-llm.com/submit) or [Add a provider](https://github.com/nejib1/Free-LLM/issues/new?template=add-provider.yml) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md) |
| Anything else (partnerships, press, legal) | [free-llm.com/contact](https://free-llm.com/contact) |

## Before you ask

- **Router:** run `free-llm doctor` and read the [router FAQ](router/README.md#faq). Most "it doesn't answer" reports are a provider that is out of quota with no second key configured.
- **A provider rejects your key:** check the provider's page on free-llm.com first. Free tiers end without notice, and the page says so when it happens.
- **Directory data:** the README tables are rebuilt every day from free-llm.com. If the site is right and the README is behind, it will catch up within a day.

## What we can't help with

We list free tiers; we don't run them. For account problems, billing or a
suspended key, contact the provider. Each provider page links to its official
documentation and terms.
